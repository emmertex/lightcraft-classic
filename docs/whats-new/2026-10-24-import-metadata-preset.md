### Metadata presets in the Import dialog
- Apply metadata presets directly from the Import dialog, with the Metadata option always visible alongside develop presets and keywords (issue #467).
- Preselects the default metadata preset configured in Settings ▸ Import.
- Create new metadata presets inline with preset name, creator, and copyright fields, or import existing presets (`.lrtemplate`, `.xmp`, `.lcmeta`, `.zip`) without leaving the dialog.
