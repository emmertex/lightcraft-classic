### Lens correction cropping
- Optical distortion and lateral chromatic aberration corrections automatically inscribe the crop within valid image pixels so corrected photos no longer show blank border margins or false highlight spikes in the histogram (issue #211).
- Added the **Constrain Crop** checkbox to the **Optics** panel and clamped Crop tool handles to the valid post-correction image boundary.
- Canon CR2 and CR3 files whose lens name is recorded only in the Canon MakerNote now match lens database profiles on import.
