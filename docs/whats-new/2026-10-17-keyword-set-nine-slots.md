### Keyword Set shows its nine slots from the start (issue #220)
- Under Keywording, a keyword set with nothing in it yet (Recent Keywords before you add any) shows its nine empty
  slots instead of a sentence about them. They fill as you add keywords, and each one names its shortcut on hover
  (⌥1–⌥9 on macOS, Alt+1–Alt+9 elsewhere, where the tooltips used to say ⌥ too).
