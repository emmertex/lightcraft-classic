### Edit In uses the editors you set up
- Over MCP, the control channel and in actions, Edit In opens only an editor you set up: a saved Edit In preset, or the one in Settings ▸ External Editing. A request there that names another program is refused; the command line (`run` without `--connect`) and the Edit In Presets dialog still take one.
- On Windows, a copy sent to the system's default editor opens without going through the command prompt.
